# NooFu Arranger

Maintenir cette application dans app/. Aucun fichier audio du projet musical ne doit entrer dans app/public, dist ou un commit de l’application. Les imports utilisateur restent locaux. Ne pas modifier la musique en développant l’application. Conserver les stores IndexedDB et tester les migrations. Incrémenter version/CHANGELOG pour une évolution significative. Exécuter typecheck, lint, tests et build ; vérifier l’interface mobile. Ne pas rendre le dépôt NooFU public pour activer Pages.
